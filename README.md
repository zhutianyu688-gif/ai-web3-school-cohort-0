## 目录结构
```
├── README.md              # 项目说明
├── profile.md            # 个人画像和偏好
├── learning-plan.md      # 学习计划
├── daily/                # 每日学习记录
├── tasks/                # 任务管理
├── experiments/          # 实验和项目
├── handbook-feedback/    # Handbook反馈
├── hackathon/            # Hackathon项目
├── submissions/          # 提交记录

    ├── daily-note.md     # 每日笔记模板
    └── task-note.md      # 任务笔记模板
```

## 使用说明
1. 每日学习记录放在 `daily/` 目录下
2. 任务跟踪放在 `tasks/` 目录下
3. 实验项目放在 `experiments/` 目录下
4. Handbook反馈放在 `handbook-feedback/` 目录下
5. 使用模板文件保持记录格式一致

## 打卡流程
1. 查看WCB Learning页面确认今日课程
2. 阅读Handbook相关章节
3. 在 `daily/` 目录创建今日学习记录
4. 生成打卡内容
5. 手动提交到WCB平台

## Handbook Feedback 流程
1. 学习时发现概念不清、错别字、资料过期或结构建议
2. 在 `handbook-feedback/` 新增一条 feedback 记录
3. 每条记录尽量包含：Handbook 页面链接、问题描述、建议改法、来源日期
4. 不写入隐私信息、内部链接或未公开资料

## 贡献指南
- 保持记录的及时性和准确性
- 提供具体的反馈和建议
- 遵循开源社区的规范
