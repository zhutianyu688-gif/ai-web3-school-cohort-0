# Hackathon Demo Idea

## 一句话项目描述
用AI帮助Web3新手把学习过程转化为可公开的proof-of-work，并沉淀可提交、可复盘、可展示的Hackathon demo。

## 目标用户
- Web3新手
- 想参加Hackathon但不会脚本或缺少开发经验的学习者

## 核心场景
- 每天读取课程与Handbook
- 生成最小学习路径和打卡草稿
- 收集Handbook feedback
- 把学习过程沉淀到公开GitHub仓库

## 最小可演示功能
- [ ] 个人画像输入
- [ ] 今日学习计划生成
- [ ] 打卡草稿生成
- [ ] Handbook feedback模板生成
- [ ] GitHub proof-of-work目录展示
