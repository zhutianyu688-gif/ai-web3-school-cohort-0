# Handbook Feedback 流程

这个目录记录学习过程中发现的 Handbook 问题和改进建议。每条 feedback 尽量做到可以公开索引、可以被维护者理解、可以被后续合并。

## 记录标准

每条 feedback 尽量包含:

- Handbook 页面链接
- 问题描述
- 建议改法
- 来源, 例如 daily note、实验记录、截图或相关链接
- 状态: draft / ready / submitted / merged

## 工作流

1. 学习时发现问题, 先在 daily note 里写候选。
2. 候选成熟后, 复制 `templates/handbook-feedback.md` 到本目录。
3. 整理成可提交版本。
4. 你确认后, 再通过 GitHub issue / PR / 页面编辑入口提交。
5. 提交链接写回对应 feedback 文件和 daily note。

## 提交入口

- Handbook: https://aiweb3.school/zh/handbook/
- 参与共建: https://aiweb3.school/zh/contribution/
- GitHub repo: https://github.com/lxdao-official/aiweb3school
